# Security Policy

## Supported Versions

Only the latest release is supported with security updates. The Docker image tags `latest`, `0` and the newest `X.Y` and `X.Y.Z` follow it; see [CHANGELOG.md](CHANGELOG.md).

## Reporting a Vulnerability

Report security problems privately through the Security tab of this repository (a private security advisory). Do not open a public issue or pull request for a vulnerability, and never include secrets, real addresses or personal data in a report.
